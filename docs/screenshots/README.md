# Screenshots

Letakkan tangkapan layar fitur di folder ini dengan nama berikut agar tampil di `README.md`:

| Berkas | Halaman |
|--------|---------|
| `01-landing.png` | Landing page publik |
| `02-dashboard.png` | Dashboard warga |
| `03-kas.png` | Kas Transparan (grafik + riwayat) |
| `04-iuran.png` | Iuran Saya + popup Midtrans Snap |
| `05-surat.png` | Surat: form + daftar + download PDF |
| `06-verify.png` | Halaman verifikasi QR publik (`/verify/{token}`) |
| `07-lapor.png` | Lapor Warga + timeline penanganan |
| `08-admin.png` | Panel Admin Filament (pengurus) |
| `09-inklusif.png` | Mode Inklusif aktif (teks besar + kontras) |

**Cara cepat mengambil screenshot:**
1. `php artisan serve` lalu login dengan akun demo (lihat README).
2. Buka tiap halaman, ambil tangkapan layar (desktop & mobile).
3. Simpan dengan nama di atas ke `docs/screenshots/`.
